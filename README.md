# Save Image As

Расширение для Chromium и Yandex Browser: сохраняет изображения в оригинальном формате, PNG, JPG или WebP.

## Возможности

- Контекстное меню по правому клику на изображении.
- Системное окно выбора места и имени файла при сохранении.
- Сохранение оригинала без перекодирования.
- Конвертация в PNG, JPG и WebP.
- Настройка качества для JPG/WebP.
- Современное компактное окно настроек.
- Настройки синхронизируются через Chrome Storage.

## Установка для разработки

1. Скачайте репозиторий кнопкой **Code → Download ZIP** и распакуйте архив.
2. Откройте страницу расширений браузера:
   - Chrome: `chrome://extensions`
   - Yandex Browser: `browser://extensions`
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку проекта.

## Использование

Нажмите правой кнопкой мыши по изображению и выберите **Сохранить изображение как…**, затем нужный формат.

## Ограничения первой версии

- SVG сохраняется только как оригинал: растеризация SVG намеренно не выполняется.
- GIF сохраняется только как оригинал, чтобы не потерять анимацию.
- JPG не поддерживает прозрачность: прозрачные области заполняются белым.
- Для конвертации сайт должен разрешать получение изображения расширением. Если сервер блокирует запрос или требует авторизацию, конвертация завершится понятной ошибкой.
- Анимированные изображения, кроме GIF, также могут потерять анимацию при преобразовании; для сохранения движения используйте оригинальный формат.

## Проверки

GitHub Actions автоматически проверяет корректность JSON-манифеста и синтаксис JavaScript при каждом push в `main` и при pull request. Это статическая проверка; она не заменяет ручное тестирование в браузере.

## Разработка

Manifest V3, service worker, Offscreen Document API, OffscreenCanvas и Downloads API. Внешние библиотеки не используются.
